# Manual inputs

Files the team fills in by hand. Copy a `*_TEMPLATE.csv`, remove `_TEMPLATE` from the name, fill it in.
Real files are **not** committed to Git (they stay on your laptop / the shared Google Drive).

| File | When | Guide |
| --- | --- | --- |
| `ibbi_listed_matches_reviewed.csv` | after `bpp match-names` | docs/02_phase1_cohort.md, Step 1.5 |
| `firm_financials.csv` | before `bpp build-cohort` | Step 1.6 |
| `listed_companies_extra.csv` | if a company is missing from BSE/NSE lists | Step 1.3 |
| `manual_reports.csv` | for PDFs collected by hand | docs/03_phase2_documents.md, Step 2.3 |

Dates: `YYYY-MM-DD` preferred (`DD-MM-YYYY` also works). Fiscal year = the year it ends (FY2019 = Apr 2018–Mar 2019).
